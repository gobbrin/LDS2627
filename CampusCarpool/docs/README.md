# Documentação do CampusCarpool

Índice da estrutura de `docs/`. Os documentos nomeados `Ixxx` correspondem a itens de trabalho (issues). A documentação de projeto (proposta, âmbito, requisitos, modelo de dados, casos de uso, regulamento) vive nas pastas de documentação do grupo, fora deste repositório.

| Pasta | Conteúdo |
|---|---|
| [arquitetura/](arquitetura/) | [Guia do código do backend](arquitetura/GUIA-DO-CODIGO.md): camadas, fluxo de um pedido, onde está cada funcionalidade e armadilhas. |
| [entregas/](entregas/) | Documentos de entrega por item: I029, I034–I037, I041, I044. |
| [testes/](testes/) | Especificações, evidências e relatórios de testes (I050, I053, I054, I059) e coleções Postman (I055, I034–I037). |
| [operacao/](operacao/) | Pipeline CI/CD (I058) e manual de instalação do backend (I064). |
| [qualidade/](qualidade/) | Análise estática (I056). Revisões e dívida técnica são locais (`.gitignore`). |
| [IMPLEMENTACAO-STATUS.md](IMPLEMENTACAO-STATUS.md) | Estado da implementação (desatualizado; verificar sempre no código). |

## Convenções

- Português europeu em nomes, textos e commits.
- Documentos novos entram na pasta temática correspondente; não criar ficheiros soltos na raiz de `docs/`.
- Ficheiros `.pdf` são exportações dos `.md` homónimos; a fonte é o `.md`.
